# MyESH Platform

MyESH is a comprehensive agricultural marketplace and export supply hub connecting farmers, buyers, and exporters in the Eastern Southern Highlands region.

## Live Demo

https://my-esh.vercel.app/


## Overview

MyESH is a modern web platform designed to streamline agricultural trade and knowledge sharing. It serves as a central hub for farmers, cooperatives, exporters, and buyers to connect, share market information, and access resources for mango and avocado farming.

## Features

### Core Functionality

- **User Authentication**: Secure login and registration with email/password and Google Sign-In
- **Dashboard**: Personalized overview with market prices, sourcing offers, and weekly updates
- **Sourcing Hub**: Post and browse buy/sell offers for agricultural produce
- **Market Prices**: Real-time commodity pricing with trend analysis
- **Farmer Mapping**: Interactive visualization of farmer locations and production data
- **Knowledge Hub**: Educational resources on crop production, pest control, and certification
- **News and Insights**: Market updates, policy changes, and industry alerts
- **Support Center**: Query system for farmer assistance and extension officer advice

### Key Highlights

- Dark mode support
- Fully responsive design
- Firebase authentication and Firestore database
- Profile management with farm information
- Certification tracking (GlobalG.A.P., Organic)
- Multi-language support ready

## Getting Started

### Prerequisites

- Node.js (v16 or higher)
- npm or yarn
- Firebase account

### Installation

1. Clone the repository:
``
git clone https://github.com/your-username/myesh-platform.git
cd myesh-platform
``

Install dependencies:

``
npm install
``

Configure Firebase

Start the development server:

``
npm start
``

Open your browser and navigate to http://localhost:3000
